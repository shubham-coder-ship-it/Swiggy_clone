# Swiggy Landing Page Clone

## Project Overview

This project is a responsive frontend clone of the Swiggy homepage, developed using **HTML5 and CSS3**. The objective is to recreate the original Swiggy landing page design as closely as possible, focusing on layout, colors, typography, images, spacing, and responsiveness.

## Features

### 1. Header / Navigation Bar
- Swiggy logo and branding.
- Swiggy Corporate link.
- Partner with Us link.
- Get the App button.
- Sign In button.

### 2. Main Banner
- Orange-colored hero section.
- Main heading: "Order food & groceries. Discover best restaurants. Swiggy it!"
- Delivery location input field.
- Restaurant and food search bar.
- Food-related background images.

### 3. Service Cards
Three main service cards:
- **Food Delivery:** Order food from restaurants.
- **Instamart:** Instant grocery delivery.
- **Dineout:** Discover restaurants and dining offers.

Each card includes an image, heading, description, discount information, and arrow icon.

## Technologies Used

- HTML5 – Page structure and content.
- CSS3 – Styling, layout, Flexbox, Grid, and responsive design.
- Google Fonts – Typography.
- Unsplash – Food and grocery images.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.
5. The Swiggy landing page will be displayed.

No additional installation or dependencies are required.

## Responsive Design

The webpage is designed to support:

- Desktop screens.
- Tablet screens.
- Mobile screens.

CSS media queries are used to adjust navigation, search fields, service cards, images, and spacing according to screen size.

## Important Notes

- This project focuses on frontend UI recreation.
- Search and location fields are for visual representation only.
- Navigation buttons are not connected to backend functionality.
- External images require an active internet connection.
- The project uses only HTML and CSS.

## Assignment Objective

To develop a responsive clone of the Swiggy landing page using HTML5 and CSS3 while maintaining a design similar to the original website.
